# Sun Position Service для Home Assistant

Кастомный компонент для Home Assistant, который предоставляет расширенные данные и сервисы для отслеживания положения солнца.

## 📌 Что это такое?
Стандартной интеграции солнца в Home Assistant иногда недостаточно для точной автоматизации (например, управления шторами, жалюзи или солнечными панелями). Этот компонент добавляет удобные сервисы и параметры для работы с азимутом, высотой солнца и другими астрономическими данными.

## 🚀 Установка

### Вариант 1: Через HACS (рекомендуется)
1. Откройте **HACS** в вашем Home Assistant.
2. Перейдите в раздел **Интеграции** (Integrations).
3. Нажмите на три точки в правом верхнем углу и выберите **Пользовательский репозиторий** (Custom repositories).
4. Вставьте ссылку на этот репозиторий, выберите тип **Интеграция** (Integration) и нажмите **Добавить**.
5. Найдите интеграцию **Sun Position Service**, установите её и перезагрузите Home Assistant.

### Вариант 2: Ручная установка
1. Скачайте папки и файлы из репозитория.
2. Скопируйте папку `sun-position-service` в директорию `config/custom_components/` вашего Home Assistant.
3. Перезагрузите Home Assistant.

## ⚙️ Настройка
1. Перейдите в **Настройки** -> **Устройства и службы** (Devices & Services).
2. Нажмите кнопку **Добавить интеграцию** в правом нижнем углу.
3. Найдите и выберите **Sun Position Service**.
4. Следуйте инструкциям на экране для завершения настройки.
