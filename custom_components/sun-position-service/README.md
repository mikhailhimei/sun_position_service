# Sun Position & Blind Controller (HACS Integration)

[![hacs_badge](https://img.shields.io/badge/HACS-Custom-41BDF5.svg)](https://github.com/hacs/default)
[![GitHub Release](https://img.shields.io/github/v/release/mikhailhimei/sun_position_service)](https://github.com/mikhailhimei/sun_position_service/releases)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

Кастомная интеграция для **Home Assistant**, предназначенная для адаптивного управления шторами, жалюзи и рольставнями. 

Компонент рассчитывает положение солнца (азимут и угол возвышения) относительно плоскости оконного проема и объединяет геометрическую видимость солнца с реальными показаниями люксметра/датчика освещенности, устраняя дребезг привода с помощью **эффективной инсоляции** и **гистерезиса**.

---

## 🚀 Основные возможности

* **Точная астрономическая геометрия:** Расчет на базе библиотеки `astral` с учетом системных координат Home Assistant.
* **Поддержка секторов остекления:** Принимает как одиночный азимут (например, `110`), так и диапазон углов окна (`[40, 135]`).
* **Концепция Effective Lux:** Защита от ложных закрытий штор в яркие дни, когда солнце светит мимо окна (например, на северной стороне).
* **Встроенный гистерезис:** Раздельные пороги для открытия и закрытия исключают частое переключение мотора при переменной облачности.
* **Чистый Stateless-сервис:** Поддержка ответа сервиса (`SupportsResponse.ONLY`) для прямого использования в сценариях с `response_variable`.
